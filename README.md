# HealMate

HealMate is a simple web project that simulates a health companion app.  
It provides basic features like medication reminders, a contact form, and uplifting positive messages via a **“Need a Boost?”** modal.  

This project was built with **HTML, CSS, and JavaScript**.

---

## Features

- **Medication Reminder** – Add medicines with time and get simulated reminder alerts.  
- **Positive Boosts** – A floating button opens a modal with random positive affirmations.  
- **Contact Form** – A demo form with simple validation for name, email, and message.  
- **Responsive Design** – Mobile-friendly layout with a clean blue theme (`#1976d2`).

##Usage

- Go to Medication Reminder page → fill in medicine name & time → see your log update and get a confirmation alert.
- Click Need a Boost? (bottom-right) → get a random positive reminder modal.
- Test Contact Form → try submitting valid and invalid inputs to see validation.
